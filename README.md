# Лабораторная работа: модель Розенцвейга–Макартура

Реализованы последние два дифференциальных уравнения из задания:

```text
dx/dt = αx(1 - x/K) - mxy/(a + x)
dy/dt = δmxy/(a + x) - γy
```

Где `x` — жертвы, `y` — хищники, `K` — ёмкость среды, а `m x/(a+x)` —
насыщающаяся функция потребления Холлинга II типа.

## Запуск

```bash
python3 main.py --duration 50 --step 0.05 --output simulation.csv
```

Если начальные значения не указаны, программа случайно выбирает `x(0)` от
2 до 8 и `y(0)` от 0.8 до 3.5. Для воспроизводимого случайного запуска
используется `--seed`. Например:

```bash
python3 main.py --seed 42
```

Точные значения можно передать явно:

```bash
python3 main.py --prey 4 --predator 1.5
```

Параметры модели по умолчанию выбраны так, чтобы
возникает устойчивый предельный цикл (`α=1`, `γ=0.4`, `δ=0.5`, `K=10`,
`m=1`, `a=1`). Результаты записываются в CSV с колонками `time`, `prey`,
`predator`.

## Построение графиков

Установить зависимости:

```bash
python3 -m pip install -r requirements.txt
```

Построить единый красивый рисунок:

```bash
python3 plot_results.py --input simulation.csv --output simulation.png
```

В PNG входят графики численности во времени, фазовый портрет, функция
отклика Холлинга II и формулы модели.
